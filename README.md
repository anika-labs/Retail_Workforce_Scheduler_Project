RETAIL WORKFORCE SCHEDULER

Files:
1. index.html  - page structure and forms
2. style.css   - page design and responsive layout
3. script.js   - employee, shift, assignment and conflict-checking logic

HOW TO RUN:
1. Download and extract the ZIP file.
2. Keep all three files in the same folder.
3. Open index.html in Google Chrome, Edge, or another browser.
4. Add employees. Enter available days using short day names separated by commas,
   for example: Mon, Tue, Wed, Fri.
5. Create shifts and select a date.
6. Assign employees to shifts.
7. Select a date in Daily Schedule to view shifts for that day.

FEATURES:
- Employee profiles with role and availability
- Shift creation with date and start/end time
- Employee assignment
- Availability validation
- Duplicate assignment prevention
- Overlapping shift conflict detection
- Daily schedule
- Staffing summary
- Browser localStorage saves data on the same browser/device

NOTE:
This is a simple front-end student project. Data is stored in the browser and is
not shared between different computers or browsers.
